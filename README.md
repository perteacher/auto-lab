## 📈 탐구 그래프 메이커
실험 측정값(x, y)을 표에 넣으면 그래프·추세선·기울기·R²가 바로 나오는 도구. 설치·로그인 없음, 계산은 모두 브라우저 안에서.

**사용법**
1. 예시 16종(힘과 운동·에너지 / 전기 / 물질·열·기체 / 생명·지구 — 훅·옴·보일·샤를 법칙, 자유 낙하, 냉각 곡선, 용해도 곡선, 일정 성분비, 효소 반응 속도, 운동과 맥박, 기온 감률 등)을 고르거나, 제목·변인·단위를 직접 입력
2. 표에 측정값 입력 — 엑셀에서 두 열을 복사해 첫 칸에 붙여넣어도 됨
3. 그래프 모양 선택(점 / 꺾은선 / 막대 — 막대는 여러 계열이면 묶음 막대), 추세선 종류 선택(자동 추천 / 직선 / 정비례 / 반비례 / 2차 / 없음), 필요하면 축 범위 직접 설정
4. 여러 계열(반복 실험·조건 비교): '+ 계열 추가'로 세로축 열을 최대 3개까지 — 계열마다 색·모양(●■▲)이 다르고 범례가 붙음. 모든 계열에 같은 종류 추세선을 맞추고 결과 문장에 기울기 비교가 들어감. 엑셀에서 3~4열을 붙여넣으면 계열이 자동으로 늘어남
5. "추세선으로 예측하기"에 x값을 넣으면 예측값 + 내삽/외삽 안내
6. 보고서용 결과 문장 자동 초안을 고쳐 쓰고 복사 — 추세선을 '없음'으로 두면 그래프 모양(최댓값 위치, 일정하게 유지되는 구간, 변화가 빨라지는지/느려지는지)으로 문장을 만듦

**내보내기·공유**
- 그래프 PNG 저장 (항상 1000×700)
- 공유 링크 복사 — 표·설정이 주소에 담겨 학생에게 그대로 배포
- 인쇄 / PDF — A4 한 장(학년·반·번호·이름 칸 + 실험 정보 + 표 + 그래프 + 결과). "결과 문장 대신 빈칸" 체크 시 학생 활동지로 인쇄. 측정값이 10개를 넘으면 표를 2단으로 접어 30개까지 한 장에 들어감
- 키보드: 표에서 Enter = 다음 칸(마지막 행이면 새 행), Shift+Enter = 이전 칸. 그래프에는 화면 낭독기용 요약(측정값 개수·범위·추세선)이 붙음
- 입력은 이 기기 브라우저에 자동 저장
