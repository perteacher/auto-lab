## 📈 탐구 그래프 메이커
실험 측정값(x, y)을 표에 넣으면 그래프·추세선·기울기·R²가 바로 나오는 도구. 설치·로그인 없음, 계산은 모두 브라우저 안에서.

**사용법**
1. 예시(훅의 법칙·옴의 법칙·가열 곡선·보일 법칙)를 고르거나, 제목·변인·단위를 직접 입력
2. 표에 측정값 입력 — 엑셀에서 두 열을 복사해 첫 칸에 붙여넣어도 됨
3. 추세선 종류 선택(자동 추천 / 직선 / 정비례 / 반비례 / 2차 / 없음), 필요하면 축 범위 직접 설정
4. "추세선으로 예측하기"에 x값을 넣으면 예측값 + 내삽/외삽 안내
5. 보고서용 결과 문장 자동 초안을 고쳐 쓰고 복사

**내보내기·공유**
- 그래프 PNG 저장 (항상 1000×700)
- 공유 링크 복사 — 표·설정이 주소에 담겨 학생에게 그대로 배포
- 인쇄 / PDF — A4 한 장(학년·반·번호·이름 칸 + 실험 정보 + 표 + 그래프 + 결과). "결과 문장 대신 빈칸" 체크 시 학생 활동지로 인쇄
- 입력은 이 기기 브라우저에 자동 저장
